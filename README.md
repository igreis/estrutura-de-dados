# Navegador Simples em Java 📚🌐

Este projeto simula um sistema de navegação de páginas (como um navegador web) utilizando a estrutura de dados Pilha (Stack). Ele permite navegar para novas páginas, voltar para páginas anteriores e avançar para páginas futuras, mantendo o histórico de navegação.

## 🚀 Funcionalidades
📄 1- Adicionar nova página (NewPage)

🔙 2- Voltar para a página anterior (Back)

🔜 3- Avançar para a próxima página (Next)

📜 4- Exibir histórico de navegação (Historico)

## 🧠 Estrutura
O projeto utiliza duas pilhas:

pilha – Pilha principal de navegação (histórico atual)

pilhaBack – Pilha auxiliar para armazenar páginas ao voltar

## 📁 Estrutura dos arquivos
Navegation.java – Classe principal com as funções de navegação.

Pilha.java – Implementação da estrutura de dados Pilha.

No.java – Classe auxiliar que representa os nós da pilha.z'
